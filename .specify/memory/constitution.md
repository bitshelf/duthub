# duthub Constitution

## 运行行为与证据

功能规格须列出可观察行为、失败路径和验收方式。涉及串口、USB、继电器、文件、授权或进程时，先确定目标与所有者，明确关闭、取消、权限拒绝和迟到事件的行为。将模拟验证与真机结果分别记录。

## 实现边界与验收

遵循 [AGENTS.md](../../AGENTS.md) 中的 Rust、GPUI、配置边界与回归要求。变更按可独立验证的范围提交。保留现有验收标准，行为变更有明确需求和测试依据。

## 文档与治理

[项目文档](../../docs/README.md)描述当前契约。功能规格、实施计划和任务归入 [specs/](../../specs/) 对应功能目录。ADR 保留裁决与状态；审计保留原始事实和待关闭项。实施完成后将长期需要维护的行为更新到对应的产品文档。
