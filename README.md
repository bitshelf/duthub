# duthub — 串口调试工作台

使用 AI 编写的个人嵌入式 Linux Agent 调试工具

## 系统要求

- **Windows**：最低要求 **Windows 11（Build 26100 / 24H2 及以上，且系统已启用原生 Process Security Environment / PSEC 1.1+）**
- **不支持** Windows 7、Windows 10 以及未提供原生 PSEC 1.1 的早期 Windows 11 版本
