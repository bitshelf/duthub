# duthub-a2a-integration

- Verify which service is running before probing its Agent Card. Native Settings saves and exports A2A configuration. The customer executable serves MCP independently.
- For A2A implementation status, see the [A2A guide](../../../docs/A2A_MCP_INTEROP.md). Verify discovery, message and task results, cancellation and invalid requests with a protocol client. Redact credentials.
- Review the [MCP contract](../../../docs/API_CONTRACT.md) for read-only evidence access.
