# 文档与项目技能整理

## 用户故事与验收

开发者从[文档索引](../../docs/README.md)找到当前行为、设计决策和审核证据。过时计划及重复技能清单从现行树移除，历史由 Git 保留。

代理可从仓库技能查到对应契约、源码和回归入口。MCP、A2A 与串口技能描述当前运行路径。

## 要求

- FR-001 保留可用产品文档、ADR、未结案审核和资产依赖。
- FR-002 使用目录和索引区分现行指南、设计、技术参考与历史审核。
- FR-003 保留配置示例、原型文件和生成脚本入口。文件移动只允许更新源码中的文档引用。
- FR-004 项目技能导航可解析，Spec Kit 功能规格留在 `specs/`。
