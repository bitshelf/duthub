# 运行时审核修复

## 行为与验收

- 串口关闭后由原任务释放端口和租约。迟到的缓冲清理不能丢弃新会话的串口证据。
- 继电器测试与长脉冲由端口任务完成。排队的指令有独立期限，开始执行后应报告实际收尾结果。
- USB Shell 写入在 I/O 处复核租约。关闭终端应取消排队写入并在后台收尾子进程。
- MCP 快照保留现有路径和 JSON 结构，经原子替换发布。退出时通知快照写线程停止。
- Windows 原生自检打开 Agent 设置页。烧录工具页去掉说明小字，串口规则旁显示匹配含义。新建配置预置串口留空的 `ch340-relay`。
- 串口视口为虚拟列表分配高度。连接后直接按 Enter，应在窗口显示设备返回的提示符和后续键入回显。
- Agent 配置保留状态和错误反馈，统一 API Key 控件并移除说明小字。
- MCP 服务在串口配置下方常驻。A2A 和采集设备使用同样的标题栏开关。窄布局中说明换行，开关留在卡片内。
- 点击关闭并隐藏到托盘时保持静默。真实告警继续按原路由通知。
- 串口回滚缓冲默认 1,000,000 行，可编辑为更大值。终端右键菜单移除「更早输出」和结构化日志入口。
- 串口日志始终保存。连接管理按 DUT 设置启动分割、参考文件和最低相似度，默认关闭分割、相似度为 95%。关闭时跨会话追加到 `logs/serial.txt`，通过 MCP 可查询。存在旧 DUT 的同名目录时，保留旧归属和历史记录。
- Windows 沙箱内的 PowerShell 从当前 DUT 的工作目录启动。默认驱动器无法定位时，在进程内挂载该目录，保持原有文件权限和 Job Object 限制。
- 限制实时帧的行数。串口 actor、事件总线和桌面共享网格快照，终端高亮规则每次渲染只取一份。

## 回归

默认回归运行工作区格式、Clippy 和测试。需要检查窗口时，显式在回归最后运行桌面自检。用 COM31 真机记录回车发送、回显和实际画面，并连续校验空格和退格的目标光标行。用稳定长历史比较网格快照成本，继电器时序用假驱动验证。

- COM31（115200、8N1）各测 120 次。按键入队至目标快照的 p95 为 14.4 ms（空格）和 13.9 ms（退格），最大值为 31.5 ms 和 14.8 ms。
- 同一份 10,000 行历史网格中，单次提取快照的中位耗时为 19.10 ms（4,000 行）和 4.72 ms（1,000 行）。这项测试只测快照提取。
