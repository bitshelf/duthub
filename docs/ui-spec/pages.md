# 页面与交互规格（GPUI 移植对照）

> 来源：`duthub.html`（原标注「V35 冻结原型」——**溯源注记（2026-11-23）**：现存文件为 2026-11 一比一离线复刻版（HTML meta 自述「2026-11 构建对齐」），V35 原版已不可对现存文件复核；现存顶层 `<section class="view">` 仅 **2** 个（`viewHome`/`viewSerial`），其余界面以 `cfg-page` 配置浮层承载（agent/flash/adb/relay/media/settings 六页，`data-page` 实测 6 处）。本清单的 `page-*` id 为 V35 历史枚举，与现存 HTML id 不同名，按各节功能内容对照）。
> `43c58dc:docs/IMPLEMENTATION_PLAN.md` M0.5 提到的"7 大页面"以本清单实际枚举为准。

## 1. `page-serial` 串口工作台（主界面）

Zed 式单画布：左侧功能 rail（49px）+ 串口编辑器 + 可选 Agent 侧栏（可拖拽分栏）。

- **Tab 栏**：会话 tab（编号、状态点、关闭按钮）、新增按钮、tab 右键菜单（重命名/属性/复制输出/清空/关闭其他/关闭）、双击重命名、标签属性弹窗（改名/换 host/port/baud，含冲突校验）
- **终端视图**：追加式滚动日志（prompt 高亮、自定义正则高亮、错误行配色）、行内输入行（历史上下键、草稿保持）、点击聚焦
- **查找条**：Ctrl+F 开启，计数、上/下一个、高亮所有命中
- **命令 dock**：底部快捷命令条（图标化 pill、配置菜单、拖拽排序、添加命令弹窗带图标选择网格）
- **工具条**：查找入口、REC 录制标记（录制/停止/回放）、复制日志、清空会话
- **终端右键菜单**：查找、复制、清空、命令管理
- **空态**：无会话时引导创建（含示例建议）

## 2. `page-connection` 连接管理

- DUT tab 条（与串口会话联动）+ 新增 DUT
- **串口绑定**：host 下拉、端口 combobox（过滤下拉 + 手动输入）、波特率 combobox（自定义值）、数据格式
- **USB ADB**：模式选择、序列号 combobox（候选来自 `adb devices -l`，可手动输入）
- **控制单元**：disabled / USB 继电器（节点+驱动+4 通道勾选+通道编号）/ SNMP PDU（地址+版本+凭据引用+插座号），按模式显隐
- **MCP 映射**：stdio（命令/参数/工作目录/环境变量）或 Streamable HTTP（完整 URL），连接预览
- **烧录工具**：可执行文件、测试参数、内联测试运行器（命令预览 + stdout 输出区 + 状态徽标）
- 保存/删除 DUT（含同端口冲突校验）

## 3. `page-agent` Agent 工作区（kres 式）

- 左侧会话列表 + 目标 DUT 元信息 + 运行模式入口
- 顶栏：工作流标题 + 状态 + 会话/检查器开关
- 配置条：provider、fast/slow 模型、目标、展开项（turns、并行度、对比、审批开关）
- 5 阶段进度条（步骤块 + 度量文本）
- 内容区：空态建议、活动时间线（步骤卡 + 事件代码块）、findings 列表
- 编辑器：指令输入 + 发送/停止 + 主机徽标
- 检查器：设备映射行、角色行、TODO 列表、策略说明
- LLM 模型目录：增删改模型、测试连接（状态/延迟/响应展示）、获取模型列表、密钥仅存会话
- A2A 设置：本机 Agent 名称/端口、Agent Card URL、导出服务器配置、远端 peer 列表（添加/检查/编辑/删除，URL 校验）

## 4. `page-settings` 设置

- 外观：主题（dark/light/system）、语言（zh/en/system）、平台外观（Windows/Wayland/TUI 皮肤）（**注记（2026-11-23）**：「平台外观」在现存 HTML 设置页无此项（grep「平台外观」0 命中），V35 历史条目，现行桌面设置亦无对应项）
- 终端：跳转最新、显示命令条、tab 编号、tab 状态图标、包含 ANSI
- 正则高亮：表达式 + 颜色 + 实时预览
- 自定义命令：列表管理（拖拽排序）
- 烧录预设：预设库 CRUD（独立弹窗编辑）（**注记（2026-11-23）**：现存 HTML 中烧录预设已移至配置浮层 `data-page="flash"` 页（HTML:713 实测），不在设置页内）
- 配置文件：settings/duts 导出/JSON 编辑器（校验后保存）

## 5. 配置浮层（config shell）

Zed 式大浮层（左导航 + 搜索 + 右内容）：承载连接管理/设置两个页面的浮层形态，导航计数徽标、过滤隐藏不匹配项。

## 6. 全局组件

- 通知 toast（右上角（HTML:383 实测 `top:46px;right:14px`——原「右下角」为 V35 旧值），2.4s 自动消失）
- 确认弹窗（危险操作）
- 上下文菜单系统（tab/终端/命令三类，键盘可达、边界翻转）
- 左侧 rail：品牌入口（workspace 菜单：连接管理/设置/Agent 面板开关）、页面图标导航
- i18n：全部 UI 文案 zh/en 双语（见 `i18n.md`——**注记（2026-11-23）**：原「93 键」为 V35 内嵌 i18n 表数值，现存 HTML 无内嵌 i18n（grep 0 命中）；应用 locales `apps/desktop/locales/zh-CN.json` 与 `en-US.json` 现各 **683 键**（2026-11-23 实测））；主题 token（见 `theme.md`）
- 快捷键：Enter 发送、Shift+Enter 换行、Ctrl+F 查找、Esc 关闭浮层/菜单
